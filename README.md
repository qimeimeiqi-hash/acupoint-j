# 2岁儿童穴位立体图

面向推拿新手家长的小儿推拿辅助工具：在卡通人体图上标注穴位，点击查看定位与手法，帮助在家按处方完成推拿。

> ⚠️ 本工具仅用于辅助记忆穴位位置与手法，不构成医疗建议，不能替代医生诊断。具体推拿频次、力度、疗程请严格遵医嘱。

完整需求、设计与开发规范见 [`CLAUDE.md`](./CLAUDE.md)。

## 本地运行

纯静态网站，无需构建。用任意本地静态服务器打开 `index.html` 即可（不要直接双击用 `file://` 打开，会影响部分功能）。

## 运行测试

```
npm test
```

使用 Node.js 内置的 `node:test`，零第三方依赖。
